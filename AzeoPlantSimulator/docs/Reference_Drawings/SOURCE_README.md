# AzeoPlant Process and High-Performance HMI Assets

This package contains the generated process overview, individual unit P&IDs, and high-performance HMI Level 1 through Level 4 screens.

## Folders

- `01_Original_PNG_Concepts/` — original generated concept PNGs from the design conversation.
- `02_Vector_SVG/` — editable SVG redraws using vector shapes, text, lines, symbols, and scalable `viewBox` geometry.
- `03_Vector_PNG_Renders/` — PNGs rendered directly from the matching SVG files for exact SVG/PNG parity.

All SVG files use a 1448 × 1086 viewBox (4:3) and `preserveAspectRatio="xMidYMid meet"` so they scale without geometric distortion.

The P&IDs are conceptual training/simulator drawings rather than issued-for-construction engineering drawings. Tags and process details should be validated against the final simulator tag database and control narratives before implementation.
