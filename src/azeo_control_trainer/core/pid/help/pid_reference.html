PID Function Block — Parameter Reference

Comprehensive guide to all PID block parameters, modes, and configuration options.
Based on Azeo PID function block specification with full industrial feature set.

Overview

The PID Function Block implements a full-featured industrial PID controller with:
  • Standard and Series PID equation forms
  • 8 operating modes: OOS, IMan, LO, Man, Auto, Cas, RCas, ROut
  • 8 structures including Two Degrees of Freedom (Beta/Gamma)
  • PIDPlus adaptive gain with saturation recovery
  • Nonlinear gain modification (NL_GAP, NL_TBAND, NL_HYST)
  • Feedforward with configurable gain and scale
  • Anti-Reset Windup with Dynamic Reset Limiting (DRL)
  • Signal linearization (square root for flow)
  • Remote shedding with configurable timeout actions
  • Cascade initialization via BKCAL_IN / BKCAL_OUT
  • 6-point alarming: HI_HI, HI, DV_HI, DV_LO, LO, LO_LO
  • Output tracking for overrides and interlocks
  • Process variability monitoring (STDEV)

Mode Priority (highest to lowest):
  • OOS — Block is offline. Output held. All alarms suppressed.
  • IMan — Downstream block not ready. Output tracks BKCAL_IN. Automatic mode.
  • LO — External interlock active. Output follows TRK_VAL. Cannot be overridden by operator.
  • Man — Operator directly sets output. No PID calculation. SP optionally tracks PV.
  • Auto — PID controls output to maintain SP. Operator sets SP.
  • Cas — SP driven by upstream controller via CAS_IN. PID controls output.
  • RCas — SP driven by remote host via RCAS_IN. Subject to SHED_TIME timeout.
  • ROut — Output driven by remote host via ROUT_IN. Subject to SHED_TIME timeout.
Mode Shedding: Higher-priority modes always override lower ones. If a remote connection times out (SHED_TIME), the block automatically sheds to a safer mode based on SHED_OPT configuration.

PID Equation

Standard (ISA) Form:
OUT = Kp × [ e(t) + (1/Ti) ∫ e(τ) dτ + Td × de(t)/dt ] + Bias
Series (Interacting) Form:
OUT = Kp × (1 + 1/(Ti·s)) × (1 + Td·s) × e(t)
Where: e(t) = SP - PV (reverse acting) or e(t) = PV - SP (direct acting).
The derivative is filtered: Td_eff = Td / (1 + α·Td·s)

Tuning Parameters

gain float Azeo: GAIN
Controller Gain (Kp) — Multiplier on the error signal.
Higher values give faster, more aggressive response but risk oscillation. In Standard form, gain affects all three terms (P, I, D) simultaneously. In Series form, gain only multiplies the proportional path.
  • Increase for sluggish response (underdamped)
  • Decrease for oscillatory response (overdamped)
  • Set to 0 to disable proportional action (integral-only control)
Range: 0 – 999  |  Default: 1.0  |  Typical: 0.5 – 2.0
reset seconds Azeo: RESET
Integral Time (Ti) — Time for the integral term to repeat the proportional action.
Smaller Ti = faster integral action = eliminates steady-state offset quicker, but too small causes integral windup and oscillation. Set to maximum (9999) to effectively disable integral action (P or PD control).
Range: 0 – 9999 s  |  Default: 60.0 s  |  Typical: 2 – 120 s
rate seconds Azeo: RATE
Derivative Time (Td) — Predictive term that responds to rate-of-change.
Higher Td = more damping on fast disturbances. Set to 0 for PI control only (most common). Use with caution on noisy signals. Always use with the derivative filter (α).
  • Effective on temperature, level, and slow pressure loops
  • Generally avoided on flow loops (too noisy)
Range: 0 – 9999 s  |  Default: 0.0 s  |  Typical: 0 – 30 s
alpha float Azeo: ALPHA
Derivative Filter Coefficient (α) — First-order filter on the D-term.
Filters the derivative to limit high-frequency noise amplification: Td_eff = Td / (1 + α·Td·s). Increase if D-term is noisy; decrease for faster derivative response.
Range: 0.05 – 1.0  |  Default: 0.125  |  Typical: 0.1 – 0.2
pv_ftime seconds Azeo: PV_FTIME
PV Input Filter Time Constant — Low-pass filter applied to PV before PID calculation.
Smooths sensor noise. Set to 0 for no filtering. Too large adds phase lag and reduces loop stability. Applied after linearization (L_TYPE) but before the PID error calculation.
Range: 0 – 9999 s  |  Default: 0.0 s  |  Typical: 0.5 – 5 s
sp_ftime seconds Azeo: SP_FTIME
SP Filter Time Constant — Softens setpoint step changes into smooth ramps.
Reduces overshoot on SP changes. Only affects SP response; disturbance rejection is unaffected. Set to 0 to disable. Use in combination with SP rate limits for comprehensive SP shaping.
Range: 0 – 9999 s  |  Default: 0.0 s
sp_rate_up / sp_rate_dn EU/s Azeo: SP_RATE_UP / SP_RATE_DN
SP Rate Limits — Maximum rate of SP change (EU per second).
  • sp_rate_up: Max rate SP can increase. 0 = immediate (no limit).
  • sp_rate_dn: Max rate SP can decrease. 0 = immediate (no limit).
Used to ramp SP slowly, protecting equipment from thermal shock or pressure transients. Example: 2 psig/s for pressure, 5 °F/s for temperature controllers.
Range: 0 – 9999 EU/s  |  Default: 0.0 (no limit)
ff_gain float Azeo: FF_GAIN
Feedforward Gain — Scales FF_VAL before adding to output.
OUT += FF_GAIN × FF_VAL. Set to 0 to disable. Requires ff_enable = True. Used for measurable disturbance rejection (e.g., steam flow feedforward to level control).
Range: −999 – 999  |  Default: 1.0
ideadband EU Azeo: IDEADBAND
Integral Deadband — Suppresses integral action when error is small.
When |error| < ideadband, integral accumulation is frozen. Prevents limit-cycle oscillation on processes with deadband (e.g., sticky valves). Set to 0 to disable.
Range: 0 – 9999 EU  |  Default: 0.0  |  Typical: 0.5 – 2× noise level
beta / gamma 0–1 Azeo: BETA / GAMMA
Two Degrees of Freedom — Independent SP response vs disturbance rejection tuning.
  • Beta (β): Proportional SP weight. P-term = Kp × (β·SP − PV). β=0: no P kick on SP change. β=1: full proportional response.
  • Gamma (γ): Derivative SP weight. D-term acts on (γ·SP − PV). γ=0: derivative on PV only (no SP kick). γ=1: derivative on full error.
Only active when Structure = TWO_DOF.
Range: 0.0 – 1.0  |  Default: β=1.0, γ=0.0
form / structure enum Azeo: FORM / STRUCTURE
PID Form and Structure — Control equation type and where P/I/D act.
FormDescription
STANDARDISA form — gain affects all terms. Most common.
SERIESInteracting form — I and D decoupled. Matches legacy DCS tuning.
StructureDescription
PID_ON_ERRORAll terms act on error (SP−PV). Fastest SP response.
PI_ERROR_D_PVP+I on error, D on PV only. Default — prevents derivative kick.
I_ERROR_PD_PVI on error, P+D on PV. Smoothest SP response.
PD_ON_ERRORNo integral — P+D on error only.
P_ERROR_D_PVNo integral — P on error, D on PV.
ID_ON_ERRORNo proportional — I+D on error.
I_ERROR_D_PVNo proportional — I on error, D on PV.
TWO_DOFUses Beta/Gamma SP weights for independent tuning.
bal_time seconds Azeo: BAL_TIME
Balance Time — Bias dissipation time for P and PD structures.
For structures without integral action, the manual bias is dissipated exponentially over BAL_TIME seconds after switching to Auto. Provides smooth transition from manual bias to pure proportional control. Set to 0 for immediate bias removal.
Range: 0 – 600 s  |  Default: 0.0 s  |  Typical: 30 – 120 s

Limits

Alarm Limits

hi_hi_lim / hi_lim / lo_lim / lo_lo_lim EU Azeo: HI_HI_LIM, HI_LIM, LO_LIM, LO_LO_LIM
Absolute PV alarm limits — triggers when PV crosses these thresholds.
  • HI_HI_LIM: Critical (red) alarm. Set to +INF to disable.
  • HI_LIM: Warning (yellow) alarm. Set to +INF to disable.
  • LO_LIM: Warning (yellow) alarm. Set to −INF to disable.
  • LO_LO_LIM: Critical (red) alarm. Set to −INF to disable.
Alarms clear when PV returns past the limit by ALARM_HYS amount.
dv_hi_lim / dv_lo_lim EU Azeo: DV_HI_LIM / DV_LO_LIM
Deviation Alarm Limits — triggers when PV deviates from SP.
  • DV_HI_LIM: Triggers when PV > SP + DV_HI_LIM.
  • DV_LO_LIM: Triggers when PV < SP + DV_LO_LIM (typically negative).
Deviation alarms move with SP. Automatically suppressed during SP changes.
Typical: ±5 – 15% of PV span
alarm_hys EU Azeo: ALARM_HYS
Alarm Hysteresis — PV must return past limit by this amount before alarm clears.
Prevents alarm chattering when PV oscillates near a limit.
Range: 0 – 9999 EU  |  Default: 0.0  |  Typical: 1 – 2% of PV span

Output Limits

out_hi_lim / out_lo_lim % Azeo: OUT_HI_LIM / OUT_LO_LIM
Output Limits — Clamps controller output to protect equipment.
  • OUT_HI_LIM: Maximum output. Typical 100%. Reduce for equipment protection.
  • OUT_LO_LIM: Minimum output. Typical 0%. Raise for minimum flow requirements.
Can be bypassed in Manual mode with no_out_limits_in_man = True.
Default: 0 – 100%

Setpoint Limits

sp_hi_lim / sp_lo_lim EU Azeo: SP_HI_LIM / SP_LO_LIM
Setpoint Limits — Prevents operator from setting SP outside safe range.
Applied in Auto and Cas modes. Can be enforced in Cas/RCas with obey_sp_lim_cas_rcas = True.

Anti-Reset-Windup Limits

arw_hi_lim / arw_lo_lim % Azeo: ARW_HI_LIM / ARW_LO_LIM
ARW Limits — Stops integral accumulation when output exceeds these levels.
Prevents integral windup during output saturation. Typically set equal to or slightly beyond the output limits. When output exceeds ARW limits, integral action freezes until the output returns to the active range.
Default: same as OUT_HI_LIM / OUT_LO_LIM

Options

FRSIPID Options

use_pidplus bool Azeo: FRSIPID_OPTS.PIDPlus
PIDPlus Algorithm — Automatic gain adaptation based on PV noise.
Dynamically adjusts effective gain for optimal response across varying process conditions. Useful for nonlinear or variable-deadtime processes.
use_nonlinear_gain bool Azeo: FRSIPID_OPTS.NL_Gain
Nonlinear Gain Modification — Variable gain schedule based on error magnitude.
  • Inside NL_GAP: gain reduced to Kp × NL_MINMOD
  • Inside NL_TBAND: gain transitions linearly
  • Outside NL_TBAND: full gain Kp applied
Reduces limit cycling while maintaining disturbance rejection.
dynamic_reset_limit bool Azeo: FRSIPID_OPTS.DRL
Dynamic Reset Limiting (DRL) — Limits integral based on downstream capacity.
Uses BKCAL_IN feedback to limit integral action to what the downstream block can actually accept. Prevents integral windup in cascade configurations when secondary loop is saturated.
use_delayed_out_bad_pv bool Azeo: FRSIPID_OPTS.Delayed_OUT
Delayed Output on Bad PV — Holds output on transient sensor failures.
When PV goes BAD, holds the output at last good value for one scan, then slowly ramps. Prevents sudden output jumps on transient sensor failures.
recovery_fltr 0–1 Azeo: RECOVERY_FLTR
PIDPlus Saturation Recovery Filter.
Controls how aggressively PIDPlus exits output saturation. 0 = aggressive (fast recovery, risk of overshoot). 1 = conservative.
Range: 0.0 – 1.0  |  Default: 1.0

Control Options

direct_acting bool Azeo: CONTROL_OPTS.Direct
Controller Action Direction.
  • Direct (True): Output increases when PV increases. Example: cooling valve.
  • Reverse (False): Output increases when PV decreases. Example: heating valve. Most common.
bypass / bypass_enable bool Azeo: CONTROL_OPTS.Bypass
Bypass Mode — PV passed directly to output (open-loop).
Both bypass_enable AND bypass must be True for bypass to activate. Two-step requirement prevents accidental bypass. Used for commissioning and testing.
sp_pv_track_* bool Azeo: CONTROL_OPTS.SP_PV_Track
SP Tracks PV — In specified modes, SP is set equal to PV.
  • sp_pv_track_lo_iman: SP tracks PV in LO and IMan modes.
  • sp_pv_track_man: SP tracks PV in Manual mode.
  • sp_pv_track_rout: SP tracks PV in Remote Output mode.
Ensures bumpless transfer when transitioning back to Auto/Cas.
use_pv_for_bkcal_out bool Azeo: CONTROL_OPTS.UsePV_BKCAL
Use PV for Back-Calculation Output.
Sets BKCAL_OUT = PV instead of SP. Required in cascade configurations where the upstream controller needs the actual process value for proper anti-windup tracking.
no_out_limits_in_man bool Azeo: CONTROL_OPTS.NoOutLimMan
No Output Limits in Manual — Allows full 0–100% range in Manual mode.
obey_sp_lim_cas_rcas bool Azeo: CONTROL_OPTS.ObeySPLim
Obey SP Limits in Cascade/RCas — Enforces SP limits even with external SP sources.
track_enable / track_in_manual bool Azeo: CONTROL_OPTS.Track
Output Tracking — Output follows TRK_VAL when TRK_IN_D is True.
Used for override control, interlocks, or external output forcing. track_in_manual allows tracking even in Manual mode (normally Manual gives operator exclusive control).
ff_enable bool Azeo: CONTROL_OPTS.FF_Enable
Feedforward Enable — Enables OUT += FF_GAIN × FF_VAL path.
simulate_enabled bool Azeo: CONTROL_OPTS.Simulate
Simulation Mode — PV reads from SIMULATE_IN instead of real process input.
Used for offline testing, loop checkout, and training without affecting the live process.
act_on_ir bool Azeo: CONTROL_OPTS.ACT_ON_IR
Bias Adjustment on Transfer — Auto-adjusts bias for bumpless Man→Auto transfer.
For P and PD structures: automatically calculates the required bias so that the output does not change at the moment of transfer from Manual to Auto.
sp_track_retained_target bool Azeo: CONTROL_OPTS.SP_Track_Retained
SP Track Retain Target Mode — Preserves original target mode during SP-PV tracking.

Nonlinear Gain Parameters

nl_gap EU Azeo: NL_GAP
NL Gap — Error band where gain is reduced to Kp × NL_MINMOD.
When |error| < NL_GAP, reduced gain prevents limit cycling near setpoint. Set to 0 to disable.
Typical: 1 – 3× noise amplitude
nl_hyst EU Azeo: NL_HYST
NL Hysteresis — Prevents rapid switching between reduced and full gain.
Typical: 0.5× NL_GAP
nl_tband EU Azeo: NL_TBAND
NL Transition Band — Region where gain linearly transitions from reduced to full.
Must be ≥ NL_GAP. Wider band = smoother gain transition.
nl_minmod 0–1 Azeo: NL_MINMOD
NL Minimum Gain Multiplier — Gain inside NL_GAP = Kp × NL_MINMOD.
0.0 = zero gain inside gap (integral only). 0.5 = half gain. 1.0 = full gain (disables NL effect).

Linearization (L_TYPE)

l_type enum Azeo: L_TYPE
Linearization Type — PV signal conditioning applied before PV filter.
ValueDescription
DIRECTNo linearization — PV passes through as-is.
INDIRECTSquare root linearization for flow transmitters: PV = √(raw/span) × span
INDIRECT_SQUARE_ROOTInverse square root linearization.
low_cut / low_cutoff_enabled EU Azeo: LOW_CUT
Low Cutoff — Forces PV to 0.0 when below threshold.
Critical for zero-based flow sensors to eliminate noise near zero flow. low_cutoff_enabled must be True to activate.
Typical: 2 – 5% of PV span

Remote Shedding

shed_opt enum Azeo: SHED_OPT
Shed Option — Action on remote setpoint/output communication timeout.
ValueAction
NO_ACTIONDo nothing — remote host handles recovery.
SHED_TO_NORMALShed to next lower mode (RCas→Cas, ROut→Auto).
SHED_TO_MANUALShed directly to Manual mode.
SHED_TO_AUTOShed to Automatic mode.
shed_time seconds Azeo: SHED_TIME
Shed Time — Timeout for RCAS_IN / ROUT_IN updates.
If no new value is received within this time, the block sheds per SHED_OPT. Set to 0 to disable timeout checking.
Range: 0 – 9999 s  |  Default: 0.0 s  |  Typical: 10 – 60 s

Status Options (STATUS_OPTS)

bad_if_limited bool Azeo: STATUS_OPTS.Bad_if_Limited
Bad if Limited — Sets PV status to BAD when PV input is at a limit.
Use when a limited PV reading is unreliable (e.g., sensor pegged at 0% or 100% indicates a wiring fault).
uncertain_if_limited bool Azeo: STATUS_OPTS.Uncertain_if_Limited
Uncertain if Limited — Sets PV status to UNCERTAIN when PV is at a limit.
Less severe than Bad if Limited — reading may still be usable but confidence is reduced.
target_manual_if_bad_in bool Azeo: STATUS_OPTS.Target_Man_Bad
Target Manual if Bad IN — Latches target mode to Manual on bad PV.
Prevents automatic return to Auto when PV recovers — operator must explicitly request Auto mode. Safer for critical loops.
use_uncertain_as_good bool Azeo: STATUS_OPTS.Uncertain_as_Good
Use Uncertain as Good — Treats UNCERTAIN PV as GOOD for mode resolution.
Block stays in Auto/Cas even with uncertain PV. Useful when sensor quality fluctuates but readings are still operationally valid.

Tracking Options

track_opt enum Azeo: TRACK_OPT
Tracking Option — Behavior when TRK_VAL signal has bad quality.
ValueBehavior
ALWAYS_USE_VALUEUse TRK_VAL regardless of quality.
USE_LAST_GOOD_VALUEHold last known-good TRK_VAL.
TRACK_IF_BADActivate tracking when signal is bad.
Only relevant when track_enable = True.

Conditional Alarm

condalm_enabled bool Azeo: CONDALM_ENABLED
Conditional Alarm Enable — Master gate for all alarm evaluation.
When disabled (False), no alarms are evaluated or reported — all alarm states are cleared. Use during commissioning or when the block is in an abnormal but expected condition.
Default: True (alarms enabled)

Process Type

process_type enum Azeo: PROCESS_TYPE
Process Type — Metadata classification of the controlled process.
ValueDescription
SELF_REGULATINGProcess reaches steady state on its own (heat exchanger, pressure vessel).
INTEGRATINGProcess integrates — no natural steady state (tank level, position).
Note: Informational only — does not change PID algorithm behavior.

Diagnostics

stdev / stdev_time / stdev_cap read/config Azeo: STDEV / STDEV_TIME / STDEV_CAP
Process Variability Monitoring — Rolling standard deviation of PV.
  • stdev_time: Window duration (seconds) for rolling calculation. 0 = disabled.
  • stdev_cap: Maximum STDEV value. Clips large transients.
  • stdev: (Read-only) Current standard deviation value.
Calculated using Welford's online algorithm (numerically stable). Useful for detecting controller performance degradation, oscillation, or process upsets.
Typical: stdev_time = 30 – 120 s, stdev_cap = 1 – 2× expected variability
field_val read-only Azeo: FIELD_VAL
FIELD_VAL — PV expressed as percent of PV scale.
Calculated as: pv_scale.to_percent(PV). Useful for monitoring how far the PV is within its configured range, independent of engineering units.
nl_gain_mod read-only Azeo: NL_GAIN_MOD
NL Gain Modifier — Last computed nonlinear gain multiplier (KNL).
Shows the current gain modifier being applied (0.0 to 1.0). Useful for verifying that nonlinear gain is working as expected. 1.0 = full gain applied.
